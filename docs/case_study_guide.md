# 정성 케이스 스터디 가이드 — 상세판

클러치 프로젝트의 **정량 결론**("시즌 간 재현되는 건 역할·전반적 실력이지, 클러치 특이 능력이
아니다")을 **선수·경기 단위**로 대보는 정성 레이어. 아래 정제 CSV(`docs/case_data/`)만 열면 됩니다.

> **지표 용어**
> - **레버리지(LI)**: 이 슛이 승부를 흔드는 정도(1=평균, 3=평균의 3배, 15+=경기 좌우).
> - **기대초과**: 실제 성공(0/1) − 리그 기대 성공확률. **양수=리그 평균보다 잘함, 음수=못함.**
> - **클러치**: 종료 5분 이내 & 점수차 ≤5. **팀마진직전**: 슛 직전 (우리팀−상대) 점수차.
> - ⚠ 어시스트·턴오버는 데이터 한계로 제외(사용 금지). 기준선은 **리그 평균**(개인 평균 아님).

각 케이스는 **① 코드 → ② 예상 결과 → ③ 결론 방향** 순서로 그대로 따라 하면 됩니다.
(코드는 `docs/case_data/` 에서 R 실행 가정. 아니면 `setwd()`로 경로 지정.)

# 케이스 A. 이정현 (2025-26 MVP) — "MVP는 볼륨(역할)인가, 클러치 효율인가?"

**핵심 가설**: 리그가 인정한 MVP·클러치 아이콘이지만, *평소보다 클러치에서 더 잘 넣는 건 아닐 것*이다.

### A-0. 준비
```r
library(dplyr); library(readr)
lee  <- read_csv("case_lee_shots.csv")          # 이정현 3시즌 야투 3,146개
card <- read_csv("case_lee_season_summary.csv") # 시즌 요약카드
```

### A-1. 볼륨 vs 효율 백분위 (요약카드)
```r
card |> select(season, 클러치시도, 클러치볼륨_백분위, 클러치효율_백분위, 클러치_기대초과)
```
**예상 결과**
| season | 클러치시도 | 볼륨 백분위 | 효율 백분위 | 클러치 기대초과 |
|---|---|---|---|---|
| 2023-24 | 69 | **100** | 52 | −0.056 |
| 2024-25 | 64 | **99** | 41 | −0.111 |
| 2025-26(MVP) | 37 | **93** | 39 | **−0.139** |

→ **결론 방향**: "클러치 **볼륨**은 3시즌 리그 최상위(93~100위). 그러나 **효율**은 중간 이하(39~52위)이고
**클러치 기대초과는 3시즌 모두 음수**. MVP 시즌에도 클러치 효율은 리그 39위·기대초과 −0.14."

### A-2. 클러치 vs 비클러치 — "클러치에서 오히려 더 못 넣는다" (핵심)
```r
lee |> group_by(season) |> summarise(
  클럿_FG      = round(mean(성공[클러치]), 3),
  비클럿_FG    = round(mean(성공[!클러치]), 3),
  클럿_기대초과 = round(mean(기대초과[클러치]), 3),
  비클럿_기대초과 = round(mean(기대초과[!클러치]), 3))
```
**예상 결과**
| season | 클럿 FG | 비클럿 FG | 클럿 기대초과 | 비클럿 기대초과 |
|---|---|---|---|---|
| 2023-24 | .377 | .423 | −0.056 | +0.001 |
| 2024-25 | .297 | .380 | −0.111 | −0.037 |
| 2025-26 | .270 | .392 | −0.139 | −0.021 |

→ **결론 방향**: "비클러치 성공률(38~42%)보다 **클러치 성공률(27~38%)이 매 시즌 더 낮다.**
즉 '클러치에 강한' 게 아니라 **클러치에서 평소보다 떨어진다.** (일반적 인식과 반대)"

### A-3. 접전(±3점)일수록 더 떨어지나?
```r
lee |> filter(클러치, abs(팀마진직전) <= 3) |> group_by(season) |>
  summarise(시도=n(), FG=round(mean(성공),3), 기대초과=round(mean(기대초과),3))
```
**예상 결과**: 접전 클러치 FG .29 / .28 / **.23**, 기대초과 −0.135 / −0.123 / **−0.170**
→ **결론 방향**: "**압박이 가장 큰 접전 상황에서 효율이 가장 낮다.** 클러치 정의를 좁힐수록 나빠진다."

### A-4. 대표 슛 top5 — "기억되는 순간의 실제 결과"
```r
lee |> arrange(desc(레버리지_LI)) |> head(5) |>
  select(season, 상대팀, 남은초, 팀마진직전, 슛, 성공, 레버리지_LI, 기대초과)
```
**예상 결과**: 최고 레버리지 5개 중 **성공 1 / 실패 4** (성공은 2023-24 현대모비스전 동점 3점 +0.675, 나머지는 미스).
→ **결론 방향**: "이정현의 가장 큰 순간들도 **대부분 실패**였다. '클러치 명장면'은 소수의 성공을 선택적으로 기억한 것."

### A-5. (선택) 한 줄 요약 지표
```r
mean(lee$기대초과[lee$클러치])   # 커리어 클러치 평균 기대초과
```
**예상 결과**: **−0.095** (3시즌 통합). → 리그 평균 대비 클러치에서 슛당 약 −0.1 성공확률.

### 📝 케이스 A 최종 결론 (그대로 각색 가능)
> "이정현은 KBL이 인정한 MVP이자 대표적 '클러치 슈터'다. 그러나 데이터는 다른 그림을 보여준다 —
> **클러치 볼륨은 3시즌 리그 최상위(93~100위)지만, 클러치 효율은 중간 이하이고 기대초과는 3시즌 모두 음수**이며,
> **접전일수록 더 떨어진다.** 그의 가장 큰 순간들조차 대부분 실패였다. 즉 이정현의 '클러치'는
> **결정적 순간에 계속 공을 잡는 역할·믿음**이지, 평소를 뛰어넘는 효율이 아니다 — 프로젝트 전체 결론
> ('재현되는 건 역할, 클러치 효율이 아니다')을 리그 최고 스타 한 명으로 그대로 예시화한다."

# 케이스 B. 이선 알바노 — SK전 버저비터 2경기: "드라마는 진짜, 반복은 아니다"

2025-26 정규시즌, 알바노가 **SK 상대로 버저비터 3점을 두 번** 성공. **이 사실 자체는 100% 진짜이고 극적**이다.
케이스 B의 목표는 이 드라마를 **부정하지 않으면서** 프로젝트 결론에 정확히 연결하는 것.

### B-1. 정량 재료 (파일에서 바로)
```r
library(dplyr); library(readr)
ev  <- read_csv("case_alvano_events.csv")   # 두 경기 이벤트 + WP
sht <- read_csv("case_alvano_shots.csv")    # 두 경기 야투 + 버저비터 플래그
sht |> filter(버저비터)                      # 버저비터 두 슛
```
- **11/15 (S47G01N72)**: 동점·1초, 3점 성공, **LI 9.76**, 기대초과 +0.675 → DB 87-84 승
- **12/11 (S47G01N97)**: **1점 뒤·0초**, 3점 성공, **LI 16.67**, 기대초과 +0.675 → DB 65-63 역전승
- WP 추이(완성 그래프 `docs/img/wp_alvano_*.png`): 12/11은 DB 승리확률이 **~3% → 100%로 급반전**.
- **`case_top_moments_2025_26.csv` 에서 12/11 슛은 시즌 전체 레버리지 1위.**

### B-2. "이 드라마를 어떻게 프로젝트와 연결해 결론지을까" — 5가지 논증

이 부분이 케이스 B의 핵심입니다. 아래 5개를 엮으면 됩니다.

**① 드라마는 인정한다 (부정하지 않기)**
> "승리확률 3%에서 이겼다. 시즌 최고 레버리지 슛. 이런 순간이 스포츠의 이유다." — 먼저 이걸 분명히 인정.

**② 그러나 '2번 몰림'은 재현되는 실력이 아니라 소표본 클러스터다**
> 한 선수가 한 팀 상대로 한 시즌 버저비터 2번 = 표본 극소. 우리 전체 분석에서 **개인 클러치 효율의
> 시즌 간 지속성 r ≈ 0.02**(사실상 0). 즉 **다음 시즌 알바노가 또 버저비터를 넣을지는 예측 불가.**
> "잘하는 사람이라 넣은 것"이 아니라 "그 순간 들어간 것"에 가깝다.

**③ 알바노의 '시즌 전체' 클러치는 특별히 높지 않다 (버저 2개가 대부분)**
```r
# data/KBL_pooled_shots_scored.csv 사용
cd <- read_csv("KBL_pooled_shots_scored.csv") |> filter(season=="2025_26")
alv <- cd |> filter(shooter_en=="Ethan Alvano", clutch_std)
c(시도=nrow(alv), 성공=sum(alv$made), FG=round(mean(alv$made),3), 기대초과=round(mean(alv$make_over_exp),3))
```
**예상 결과**: 클러치 **77시도, FG 48.1%, 기대초과 +0.061**, 효율 백분위 **74**(87명 중).
→ **결론 방향**: "알바노는 이번 시즌 클러치가 평균보단 좋다(74위). 하지만 +0.061은 **소폭**이고,
그 대부분이 **바로 이 두 버저비터(+0.675 × 2)**에서 나온다. 두 슛을 빼면 사실상 평균. 즉
**'클러치 실력자'라기보다 두 번의 큰 성공이 시즌 지표를 끌어올린 것.**"

**④ 가장 극적인 순간들의 결과는 '반반도 안 된다' (기억의 편향)**
```r
top <- read_csv("case_top_moments_2025_26.csv")
c(성공=sum(top$성공), 실패=sum(top$성공==0), 성공률=round(mean(top$성공),2))
```
**예상 결과**: top30 최고 레버리지 순간 중 **성공 7 / 실패 23 → 성공률 23%.**
→ **결론 방향**: "가장 큰 순간들은 **77%가 실패**다. 우리는 알바노의 성공 2개를 기억하고 나머지 23개의
실패를 잊는다. '클러치 슈터'라는 인상은 **성공만 선택적으로 기억한 서사(생존 편향)**에 가깝다."

**⑤ '기대초과 +0.675'라는 숫자의 의미**
> 이 슛이 극적인 **이유가 곧 반복 불가의 이유**다. 기대초과가 크다 = **원래 들어갈 확률이 낮았는데 들어갔다**
> = 기대되는·반복되는 결과가 아니라 **확률을 이긴 사건**. 드라마와 재현 불가능성은 동전의 양면이다.

### 📝 케이스 B 최종 결론 (그대로 각색 가능)
> "알바노의 SK전 두 버저비터는 이 프로젝트가 **부정하려는 대상이 아니다** — 그 순간의 드라마와 가치는 진짜다.
> 우리가 말하는 건 다른 층위다. ㉠ 한 시즌 한 팀 상대 버저비터 2번은 **재현되는 실력이 아니라 변동의 산물**이고
> (개인 클러치 지속성 r≈0), ㉡ 알바노의 시즌 전체 클러치 효율은 그 두 슛을 빼면 사실상 평균이며,
> ㉢ 시즌 최고 레버리지 순간들의 **77%는 실패**다. **드라마가 진짜라는 것과, 그것이 예측·반복 가능한
> 능력이라는 것은 전혀 다른 문제다.** 알바노의 버저비터는 전자의 완벽한 예이자 후자의 반례다."
