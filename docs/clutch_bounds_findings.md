# KBL 클러치 — 배치 2: 등가검정(상한) + 승수 환산

"차이를 못 찾았다"를 **"차이가 있어도 이만큼 작다"**는 정량적 상한으로 바꾼다.
레버리지를 WP(승률) 단위로 써서 외부 상수 없이 승수로 직접 환산한다.

## 1. 클러치 실력 SD의 상한 (등가검정)

단위 = 클러치 슛 1개의 성공확률(0~1). 선수 클러스터 부트스트랩 2000회.

| 지표 | 값_슛당성공확률 |
| --- | --- |
| 클러치 실력 SD (단일시즌, 잡음보정) | 0.043 |
| └ 95% 상한                          | 0.064 |
| 슛 1개 내부 SD (순수 잡음 규모)     | 0.476 |
| SESOI (의미있는 우위)               | 0.050 |

→ 클러치 실력 SD의 95% 상한(**0.064**)조차 슛 1개 잡음(σ=0.48)의 7분의 1이며, SESOI(0.05)보다 **크다**. → SD만으로는 등가판정 보류. 단 이 SD는 **대부분 재현되지 않는 단일시즌 변동**을 포함하므로, 결정적 판단은 3절의 '재현 가능한 승수 상한'이 내린다.

## 2. 시즌 간 지속성의 상한

| 지표 | 값 |
| --- | --- |
| 시즌간 지속성 상관 r | 0.022 |
| └ 95% CI 하한        | -0.189 |
| └ 95% CI 상한        | 0.248 |
| → 재현 가능한 신뢰도 | 0.022 |

→ 지속성 상관의 95% 상한이 **0.25**에 불과 — '재현 가능한 실력'이라 부를 신뢰도(0.02)가 사실상 0. 단일시즌에 보이는 분산의 대부분은 다음 시즌에 사라진다.

## 3. 승수 환산 — '있어도 얼마나 이득인가'

클러치 슛 1개의 평균 승률 스윙 0.189 WP. 시즌 클러치 슛: 중앙 13개, 상위볼륨 45개. (정규시즌 54경기 맥락)

| 시나리오 | 중앙볼륨_승 | 상위볼륨_승 |
| --- | --- | --- |
| +1SD 선수 (단일시즌 관측 SD)   | 0.106 | 0.368 |
| +1SD 선수 (재현 가능한 실력만) | 0.016 | 0.055 |
|   └ 95% 상한 (재현 가능)       | 0.024 | 0.082 |

→ **핵심**: 단일시즌 관측 SD로는 +1SD 선수가 ~0.37승처럼 보이지만, 이는 재현되지 않는다. 실제로 **취할 수 있는(재현 가능한) 클러치 실력**은 최상위 볼륨 선수라도 95% 상한 **0.08승/시즌** — SESOI(0.5승)보다 작아 **무의미**. 즉 클러치를 근거로 한 로스터/전술 판단의 기대이득은 **사실상 0.**

## 결론

클러치 실력은 단지 '검출 실패'가 아니라, **상한을 씌워도 실전 무시 가능한 크기임이 증명**된다:
- 실력 SD 95% 상한 0.064 (슛당 성공확률) — 잡음의 7분의 1
- 지속성 상관 95% 상한 0.25 — 재현성 사실상 0
- 재현 가능한 클러치 실력의 승수 가치 95% 상한 **0.08승/시즌** (SESOI 0.5승)
